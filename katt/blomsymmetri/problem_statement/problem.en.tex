\problemname{Blomsymmetri}

Fredrik has just put new flowers on his windowsill. But something feels a bit off.
It's not quite as symmetrical as he would like it to be.

There are $K$ different flower types and each type is described by one of the integers $1,2,...,K$. The windowsill has $N$ flowers arranged in a row from left to right.
The $i$th flower from the left is of type $a_i$.
Fredrik wants the flowers to be symmetric, i.e.\ that $a_i=a_{N+1-i}$ holds for all $i$.
To achieve this, he plans to make moves that swap two adjacent flowers.
A move can thus swap flower $i$ and flower $i+1$ for some $1\le i \le N-1$.

What is the minimum number of moves required to achieve flower symmetry?
\section*{Input}

The first line of input contains two integers $N$ and $K$ ($1 \le N,K \le 200\,000$):
the number of flowers on the windowsill and the total number of types that exist.
Then follows a line with $N$ integers $a_1,a_2,...,a_N$ ($1\le a_i \le K$): the flowers on the windowsill.

It is guaranteed that there exists a sequence of moves that arranges the flowers symmetrically.

\section*{Output}

Print a single integer: the minimum possible number of moves to achieve flower symmetry.

\section*{Explanation of Samples}
In the first sample, we can start by swapping flowers 2 and 3, and then flowers 1 and 2.
Then the flowers will end up in the order \texttt{1 3 3 1}.

In the second sample, we can for example make the following 5 swaps in order:
4 and 5, 3 and 4, 1 and 2, 2 and 3, 7 and 8.
Then the flowers will end up in the order \texttt{1 2 3 1 1 3 2 1}.
