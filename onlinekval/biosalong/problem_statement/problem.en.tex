\problemname{Biosalong}

Axel and Beatrice are going to the cinema together.
They want to sit in the same row and preferably next to each other.
If there are no two free seats next to each other, they want two seats as close to each other as possible.

To find the best row to sit in, they ask you for help.
Given a description of which seats are free in a certain row,
find the shortest distance between two free seats. The distance is the number of seats between the two free seats.


\section*{Input}
The first line contains an integer $1 \le N \le 1\,000\,000$ -- the number of seats in the row we consider.

The second line contains a string of $N$ characters,
where the $i$th character is `\texttt{\#}' if the $i$th seat in the row is occupied and `\texttt{.}' if the seat is free.
It is guaranteed that at least two seats are free, i.e.\ at least two characters are `\texttt{.}'.

\section*{Output}
Print a single integer -- the shortest distance between two free seats.

\section*{Scoring}
Your solution will be tested on a set of test groups.
To earn points for a group, you must pass all test cases in that group.
